## 项目概述

这是一个围绕美团跑腿“帮取送”核心链路展开的自主体验改版原型。项目关注用户委托陌生骑手配送重要物品时的不确定感：送什么、由谁配送、当前进行到哪里，以及如何确认物品已经安全交付。

设计从服务选择、地址填写、物品信息、下单确认延伸到配送追踪与完成反馈，形成一条连续、透明、可验证的委托体验。

| 项目属性 | 内容 |
| --- | --- |
| 项目形式 | 自主命题的 UX/UI 改版与高保真交互原型 |
| 体验范围 | 帮送、帮取、1 对 1 急送的核心下单与追踪链路 |
| 工作内容 | 产品与交互定义、设计系统、视觉还原、前端原型与规则测试 |
| 原型状态 | 使用 Mock 数据，可完整体验核心流程，不接入真实交易服务 |

## 设计背景

本次自主设计聚焦三个体验问题：

- **选择是否清楚**：用户需要快速理解不同服务和运力的差异，并知道下一步需要补充什么信息。
- **托付是否安心**：重要或易损物品需要更明确的尺寸判断、配送建议、保价权益和取送凭证。
- **过程是否可感**：订单提交后，骑手身份、配送阶段、预计时间、距离和交付结果需要持续可见。

项目不以增加功能数量为目标，而是通过信息连续性和关键反馈，让每一步委托都更容易理解和确认。

## 设计目标

| 原则 | 设计表达 |
| --- | --- |
| **物可见** | 用物品类型、重量体积、备注、保价与取送凭证建立完整的物品信息链路。 |
| **人可信** | 展示骑手身份、评分、满意度和专业标签，让服务执行者更加具体可信。 |
| **事可感** | 用阶段进度、地图、预计时间、剩余距离和收货码持续反馈配送状态。 |

## 核心体验链路

```text
首页选择服务
→ 填写取件与收件地址
→ 完善物品信息
→ 比较配送方案并确认费用
→ 提交订单
→ 查看配送进度与凭证
→ 确认交付结果
```

地址、物品、配送服务和订单状态由同一份订单草稿贯穿。用户返回修改前置信息后，已填写内容不会丢失，确认页会同步呈现最新结果。

## 核心优化

### 1. 服务选择更容易理解

首页集中呈现帮送、帮取和 1 对 1 急送。服务切换会同步更新地址角色、运力信息和视觉主题，同时保持主流程入口稳定，减少模式变化带来的理解成本。

### 2. 地址角色与信息保持连续

取件和收件复用一致的填写结构，但通过标题、标签、地图标记和保存动作明确区分角色。地址交换会同步更新完整地址对象与地图表现，而不只是替换文字。

### 3. 用物品信息辅助配送决策

物品页把品类、重量、长宽高、备注和保价组织为一份完整草稿。系统根据尺寸和易损属性给出汽车配送或保价建议，同时保留用户最终选择权。

### 4. 在确认页完成服务比较

普通配送、汽车配送和 1 对 1 急送以价格、时效和权益并列呈现。用户可以返回修改地址或物品信息，再回到确认页继续下单，不需要重新填写整个流程。

### 5. 用可验证信息建立配送信任

追踪页在同一路由内推进等待接单、取件、送件、到达和完成状态，并同步展示骑手信息、地图目标、预计时间、取送凭证和收货码，让订单状态始终有迹可循。

## 原型体验

访问 [在线交互原型](https://mtpaotui.pages.dev/) 即可开始体验。

- **桌面端**：使用实机展示模式查看移动端画面，并可切换不同设备尺寸。
- **移动端**：直接打开链接体验适配后的窄屏页面。
- **推荐路径**：选择帮送 → 补全取收地址 → 选择鲜花并填写物品信息 → 比较配送方案 → 提交订单 → 查看配送追踪与完成状态。
- **数据说明**：地址、报价、骑手、配送时间和凭证均为演示数据，不会创建真实订单或发起支付。

> [!NOTE]
> 原型中的部分辅助入口会统一提示“暂未开放”，用于保持演示范围聚焦在核心下单和配送追踪链路。

## 技术实现

| 层级 | 方案 |
| --- | --- |
| 界面与路由 | React 19、React Router |
| 开发语言 | TypeScript，启用严格模式 |
| 构建工具 | Vite |
| 跨页面状态 | Zustand |
| 样式系统 | Tailwind CSS 4、CSS Custom Properties |
| 数据边界 | Repository 接口与 Mock 实现 |
| 质量保障 | TypeScript、ESLint、Stylelint、Vitest、生产构建 |

原型将页面编排、共享组件、订单状态、领域模型和数据仓库分层组织。配送阶段由 Repository 统一推进，页面只消费同一份状态快照，避免出现多条相互冲突的时间线。

## 本地运行

环境要求：Node.js 20+，pnpm 10.17.1。

```bash
pnpm install
pnpm dev
```

执行完整质量检查：

```bash
pnpm check
```

该命令会依次执行 TypeScript 类型检查、ESLint、Stylelint、Vitest 和生产构建。
