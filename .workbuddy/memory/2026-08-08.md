## 展示页二维码 → 本网站动态二维码
- 需求：把 showcase 页原来的 GitHub 二维码换成「本网站链接」的二维码，且链接以后会变，要写成动态变量。用户坚持要可扫描的二维码（不是文本链接）。
- 最终做法：
  - 新增 `src/config/site.ts` 导出 `SITE_URL = import.meta.env.VITE_SITE_URL || 'https://mtpaotui.vercel.app'`（env 未配置时回退默认）。
  - 新增 `src/vite-env.d.ts` 声明 `VITE_SITE_URL` 类型。
  - 安装 `qrcode.react`(4.2.0)；`src/showcase/ShowcaseLayout.tsx` 用 `QRCodeSVG` 按 `SITE_URL` 运行时生成二维码（扫码打开本网站），外裹 `<a href={SITE_URL}>` 兼可点击；文案「扫描二维码，在手机端全屏打开…」。
  - `showcase.css`：`.showcase-qr-card` 白底 154 卡片，新增 `.showcase-qr-link` / `.showcase-qr-card svg` 尺寸规则。
  - 删除旧的 `src/assets/showcase/github-repository-qr.png`；新增 `.env.example` 文档化 `VITE_SITE_URL`。
  - GitHub「打开」按钮保留不动（用户确认二维码与 GitHub 按钮不冲突）。
- 换域名：改 Vercel 项目环境变量或 `.env` 的 `VITE_SITE_URL` 即可，重新部署后二维码自动更新。
- 构建验证通过（index bundle 305→321KB，+16KB 来自 qrcode.react）。
