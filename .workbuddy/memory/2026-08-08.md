## 展示页二维码 → 站点链接
- 需求：把 showcase 页的 GitHub 二维码换成「本网站链接」，且链接以后会变，要写成动态变量。
- 做法：
  - 新增 `src/config/site.ts` 导出 `SITE_URL = import.meta.env.VITE_SITE_URL || 'https://mtpaotui.vercel.app'`（env 未配置时回退默认）。
  - 新增 `src/vite-env.d.ts` 声明 `VITE_SITE_URL` 类型。
  - `src/showcase/ShowcaseLayout.tsx`：移除 `github-repository-qr.png` 引用，二维码卡片改为可点击的 `<a>` 展示 SITE_URL；文案「扫描二维码…」→「点击下方链接…」。
  - `showcase.css`：`.showcase-qr-card` 适配为链接卡片，新增 `.showcase-site-link`。
  - 删除已无用的 `src/assets/showcase/github-repository-qr.png`。
  - 新增 `.env.example` 文档化 `VITE_SITE_URL`。
- 以后换域名：改 Vercel 项目环境变量或 `.env` 的 `VITE_SITE_URL` 即可，无需动代码。
- 构建验证通过（pnpm build ok）。
