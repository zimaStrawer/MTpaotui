## 底部尺寸切换器改为滑动 pill 动效（参考苹果 AirPods 分段选择器）
- 参考：用户提供的录屏（苹果官网式滑动 pill + 果冻拉伸）。方案文件 `~/.workbuddy/plans/swift-vortex-lovelace.md`，用户选定「纯 CSS + JS 测量 + WAAPI，无新依赖」。
- 修改 `src/showcase/ShowcaseLayout.tsx` 的 `DeviceSelector`：
  - 新增 containerRef / indicatorRef / animationRef / hasMeasuredRef 与 indicatorStyle state；选中项变化经 useLayoutEffect 测量新按钮 offsetLeft/offsetWidth。
  - 动画用 WAAPI 三段关键帧（550ms）：起点（当前视觉位置，连点可中途接续）→ 45% 帧 pill 拉伸覆盖新旧两按钮（easing cubic-bezier(0.2,0.9,0.25,1)）→ 终点收缩回弹（cubic-bezier(0.22,1.25,0.36,1)），fill:'both'，finished 后 cancel 落回 React 提交的 base style。
  - ResizeObserver + document.fonts.ready 瞬时重测（不播动画）；prefers-reduced-motion 直接落位；indicator 测量前不渲染避免飞入。
- 修改 `src/showcase/showcase.css`：
  - 新增 `.showcase-device-indicator`（absolute、top/bottom 6px、黄色、999px 圆角、z-index 0，不放 left/width transition）。
  - `.showcase-device-option` 加 `position: relative; z-index: 1`；`[aria-pressed='true']` 删除黄色背景仅留 `color: #18191b`；新增 pressed:hover 背景透明；文字变色改 `color 200ms ease-out 80ms` 模拟 pill 滑到才变色。
  - 顺手修复用户手动改的 `gap: 0px` → `gap: 0`（stylelint length-zero-no-unit 报错）。
- `pnpm check` 全绿。
- 后续调整：用户反馈拉伸过夸张、且 pill 前 45% 时间后缘钉在旧按钮上（视觉像「黄色赖在原地」）。已把三段关键帧改为**直接两段滑动**（420ms，easing cubic-bezier(0.22,1.25,0.36,1) 轻微过冲落位，无拉伸帧），宽度随按钮差值自然过渡。typecheck + lint 通过。
- 再调整：用户反馈 pill 移开后旧按钮文字仍停留深色约 280ms（80ms 延迟写在基础规则，进出选中共用同一条过渡）。利用「CSS 过渡取目标状态规则」改为双向分开计时：基础规则 `color 180ms ease-out`（离开选中立即变回）、`[aria-pressed='true']` 规则 `color 200ms ease-out 80ms`（进入选中等 pill 滑到再变深）；尺寸数字 span 同理（原本无过渡是瞬时跳变，补上同样双向规则）。stylelint 通过。
