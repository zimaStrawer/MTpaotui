# 2026-07-23

## 分析 awesome-design-md 仓库（VoltAgent）

用户要求评估 GitHub 项目 VoltAgent/awesome-design-md（73+ 份 DESIGN.md，从知名网站提取的设计系统文档）是否真的有利于 vibecoding 还原页面。

抽查了 5 份文件：Stripe、Apple、Notion、Tesla、Dell-1996。

核心结论：
- 文件质量高：全是精确 hex/px 值、组件级规范、Do's/Don'ts 护栏、Known Gaps 诚实声明，对 LLM 友好。
- 局限：① 只覆盖「风格语言」，不覆盖页面结构和真实内容，单靠它做不到像素级还原，需配合截图+文案；② 全部 alpha 版本，自称"灵感诠释"而非官方提取，部分组件由脚本+LLM 生成（有 TO_FILL 标记），可能存在幻觉值；③ 格式不一致（Tesla 无 frontmatter）；④ 专有字体（SF Pro/Sohne/Universal Sans）实际不可用，需用文件给的回退方案（如 Inter）。
- 最佳用法：DESIGN.md 定风格 + 截图定结构 + 自己的内容 = 高保真还原；或用于多页面风格一致性生成。
